# 拼豆工作台

一个供个人使用的拼豆库存与图纸管理工作台。使用纯 HTML、CSS、原生 JavaScript 开发，数据保存在浏览器 LocalStorage 中，无需登录、无需后端，打开即用。

## 功能概览

- **首页**：数据看板，显示色号总数、库存总量、可用库存、低库存提醒、待拼/正在拼/已完成项目数、最近库存变动和待拼项目
- **我的豆子**：管理拼豆色号库存，支持新增/编辑/删除、手动入库/减少、搜索、按品牌筛选、只看低库存
- **我的图纸**：管理拼豆图纸，支持上传预览图、添加多个色号用量、自动统计总豆子数、按分类筛选、加入待拼清单
- **待拼清单**：管理待拼项目，支持预留库存、开始制作时自动扣减库存、完成项目、取消并返还库存
- **库存记录**：查看所有库存变动历史，支持按类型筛选和搜索

## 如何启动

### 方式一：直接打开（最简单）

双击 `index.html` 文件，用浏览器打开即可使用。

> 注意：部分浏览器在 `file://` 协议下对 LocalStorage 有限制，如果遇到数据无法保存，请使用方式二。

### 方式二：本地启动一个静态服务器（推荐）

在项目文件夹下运行任一命令：

**Python 3：**
```bash
cd perder-bead-workbench
python -m http.server 8080
```
然后浏览器访问 `http://localhost:8080`

**Node.js（http-server）：**
```bash
cd perder-bead-workbench
npx http-server -p 8080
```
然后浏览器访问 `http://localhost:8080`

### 方式三：用 VS Code Live Server 插件

在 VS Code 中安装 "Live Server" 插件，右键 `index.html` 选择 "Open with Live Server"。

## 核心业务逻辑说明

### 库存计算公式

```
可用库存 = 当前库存数量 - 已预留数量
```

### 库存状态规则

| 条件 | 状态 |
|------|------|
| 当前库存 = 0 | 缺货 |
| 可用库存 < 0 | 库存不足 |
| 当前库存 ≤ 低库存提醒数量 | 库存偏低 |
| 其他 | 库存充足 |

### 预留库存逻辑

加入待拼清单时**不立即扣减当前库存**，而是增加已预留数量：

```
预留数量 = 单张图纸用量 × 制作数量
```

删除或取消**尚未开始**的项目时，自动释放预留。

### 开始制作扣减逻辑

点击「开始拼」时：
1. 再次检查库存是否充足
2. 不足则阻止并显示缺少的色号和数量
3. 充足则弹出二次确认，显示所有即将扣除的色号和数量
4. 用户确认后：
   - 从当前库存扣除实际用量
   - 从已预留数量中移除该项目的预留
   - 项目状态改为「正在拼」
   - 记录开始时间
   - 为每个色号生成库存扣减记录
   - 同一项目不能重复扣减（通过 `deducted` 标记）

### 取消已开始项目的两种选项

- **全部返还库存**：将之前扣除的所有豆子返还当前库存，生成返还记录
- **不返还库存**：不修改库存，只把状态改为已取消

## 数据说明

- 所有数据保存在浏览器的 LocalStorage 中
- 不同浏览器、不同域名下数据互不共享
- 清除浏览器数据会丢失所有记录，请注意备份
- 可在控制台执行 `JSON.stringify(Storage.exportAll())` 导出全部数据
